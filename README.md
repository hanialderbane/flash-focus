# Flash Focus v0.2.1

لعبة ويب ثنائية الأبعاد تعمل على الهاتف ويمكن تثبيتها كتطبيق ويب (PWA).

## المزايا
- العربية والإنجليزية.
- 50 مستوى تفتح بالتدرج.
- أربعة أنماط: تمييز الأشكال، الذاكرة، الأرقام، العدّ والتركيز.
- مؤقت ونقاط وثلاث نجوم لكل مستوى.
- حفظ أفضل نتيجة والتقدم تلقائياً على نفس الجهاز.
- إعدادات صوت واهتزاز اختيارية.
- Service Worker جديد باسم `flash-focus-v2`.

## النشر على GitHub Pages من الهاتف
1. فك ضغط الملف على الهاتف.
2. افتح مستودع `flash-focus` على GitHub.
3. اضغط **Add file** ثم **Upload files**.
4. ارفع الملفات الخمسة الموجودة داخل المجلد إلى جذر المستودع، مع استبدال الملفات القديمة عند الطلب.
5. اضغط **Commit changes**.
6. من Settings > Pages تأكد أن المصدر `Deploy from a branch` والفرع `main` والمجلد `/(root)`.

## ملاحظة تحديث النسخة
إذا ظهرت النسخة القديمة، افتح رابط اللعبة في Chrome ثم امسح بيانات الموقع/الملفات المخزنة مؤقتاً أو أغلق الصفحة وافتحها مجدداً. تغيير اسم الذاكرة المؤقتة إلى `flash-focus-v2` يساعد على تحميل الملفات الجديدة.

## ملاحظة
هذه نسخة ويب قابلة للتجربة، وليست ملف APK أو AAB. يمكن تغليفها لاحقاً كتطبيق Android بعد اختبارها.

## إصلاح v0.2.1
- تحسين تشغيل الصوت باستخدام AudioContext مشترك وإعادة تفعيله عند الحاجة.
- إضافة زري اختبار الصوت والاهتزاز داخل الإعدادات.
- الاهتزاز يستخدم نمطاً قصيراً متكرراً لسهولة ملاحظته.
