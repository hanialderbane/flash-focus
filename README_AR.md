# Flash Focus — النسخة التجريبية 0.1

لعبة 2D خفيفة بالعربية والإنجليزية، تعمل على الهاتف والمتصفح، ولا تحتاج إلى حساب أو خادم أثناء اللعب.

## الموجود في النسخة
- جولة مدتها 30 ثانية.
- ثلاثة تحديات: تمييز الشكل المختلف، عدّ الدوائر، واختيار الرقم الأكبر.
- نقاط وأفضل نتيجة محفوظة على الجهاز.
- تبديل العربية/الإنجليزية.
- دعم التثبيت كتطبيق ويب (PWA) والعمل دون اتصال بعد أول تحميل.

## تجربة فورية على Redmi
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى مستودع GitHub جديد باسم `flash-focus`.
3. من المستودع افتح Settings ثم Pages.
4. في Build and deployment اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. انتظر ظهور رابط GitHub Pages وافتحه من Chrome على Redmi.
7. من قائمة Chrome اختر **إضافة إلى الشاشة الرئيسية** أو **Install app** إذا ظهرت.

> يمكن فتح `index.html` محلياً للتجربة السريعة، لكن خصائص التثبيت والعمل دون اتصال تحتاج استضافة عبر HTTPS مثل GitHub Pages.

## بناء APK سحابياً
هذه النسخة الحالية PWA وليست APK أصلياً. لا يوجد مسار موثوق مضمون ومجاني بالكامل لتحويلها إلى APK من الهاتف وحده دون إعداد خدمة بناء خارجية. الخطوة التالية بعد اختبار اللعبة هي تغليفها باستخدام Capacitor ثم إعداد Android build على خدمة CI سحابية. لا ترفع مفاتيح توقيع أو كلمات مرور إلى مستودع عام.

## الملفات
- `index.html`: واجهة اللعبة.
- `style.css`: التصميم.
- `app.js`: منطق الأسئلة والوقت والنقاط.
- `manifest.json` و`sw.js`: التثبيت والتخزين المؤقت.

## ملاحظات قبل النشر والإعلانات
هذه نسخة اختبار وليست جاهزة لتحقيق دخل. اختبرها مع عدة أشخاص، أصلح الأخطاء، ثم راجع شروط المتجر وسياسات الإعلانات والخصوصية قبل إضافة أي SDK إعلاني. لا تضغط على إعلاناتك ولا تطلب من اللاعبين ذلك.
